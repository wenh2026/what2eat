# Supabase 多环境检查清单

## 使用方式
- 每个环境独立勾选，发布前必须全部为通过
- 任一阻断项失败则禁止发布

## 环境矩阵
| 检查项 | 开发 Dev | 预发 Staging | 生产 Prod | 备注 |
|---|---|---|---|---|
| Supabase URL 已配置 | ☐ | ☐ | ☐ | 与目标项目一致 |
| Supabase anon key 已配置 | ☐ | ☐ | ☐ | 非 service_role |
| Email/Password 登录已开启 | ☐ | ☐ | ☐ | Auth Provider |
| migrations 已按顺序执行 | ☐ | ☐ | ☐ | 001/002/003 |
| profiles/meals 表已存在 | ☐ | ☐ | ☐ | SQL 验证 |
| RLS 已开启 | ☐ | ☐ | ☐ | 两张表都开启 |
| policies 数量正确 | ☐ | ☐ | ☐ | 每表 4 条 |
| meals 索引已创建 | ☐ | ☐ | ☐ | user_id + 时间 |
| 新增记录可写入并回读 | ☐ | ☐ | ☐ | 登录用户链路 |
| 非本人数据不可读取 | ☐ | ☐ | ☐ | RLS 安全校验 |
| 日志事件可检索 request_id | ☐ | ☐ | ☐ | 控制台或日志系统 |
| UAT 模板已完成签字 | ☐ | ☐ | ☐ | 发布门禁 |

## 阻断项
- RLS 未开启
- policies 缺失或策略条件错误
- 非本人数据可读取
- 登录成功后无法 hydrate 历史
- 新增历史后无法编辑或删除
